Rock Paper Scissors

A Rock Paper Scissors game built using HTML, CSS and JavaScript. It lets you play against the computer, choose different difficulty levels and keep track of your performance across multiple matches.

Play the game: https://ahad123401-spec.github.io/Rock-Paper-Scissors/

Features

- Three difficulty levels: Easy, Normal and Hard
- Five match formats: Best of 1, 3, 5, 7 and 9
- Live score tracking
- Win rate and game statistics
- Winning and losing streaks
- Game history
- Achievements to unlock as you play
- Dark-themed interface
- Saves game statistics and progress using local storage

Technologies Used

- HTML5 for the game structure
- CSS3 for styling and layout
- JavaScript for game logic and interactions
- Local Storage for saving progress

Running Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.

No additional software, installation or backend server is required.
