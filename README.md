Rock Paper Scissors

A Rock Paper Scissors game built using Python, Flask, HTML, CSS and JavaScript.

Features

- Three difficulty levels
- Different match lengths
- Score and statistics tracking
- Game history
- Achievements system

How to Run

1. Install Python.
2. Install Flask using "pip install flask".
3. Run "python app.py".
4. Open "http://127.0.0.1:5000" in your browser.
